Frequently Asked Questions (FAQ)

Our tool supports all common image formats, including JPG, PNG, GIF, WebP, BMP, and TIFF. The maximum file size per image is 5MB to ensure fast processing.

Base64 strings can be used directly in HTML, CSS, or JavaScript. For example:
  • In HTML: <img src="data:image/png;base64,/9j/4AAQSkZJRgABAQ...">
  • In CSS: background-image: url('data:image/png;base64,/9j/4AAQSkZJRgABAQ...');
Base64 encoding converts binary data into text, which increases the file size by about 33%. This is normal—longer images or higher quality images will produce longer Base64 strings.
